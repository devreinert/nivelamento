Projeto individual de nivelamento.

Projeto desenvolvido com as seguintes técnologias: HTML, JS, CSS, Bootstrap.

Funcionalidades:

1 - Tela de login com validação em JS.
2 - Redirecionamento para a página "Home".
3 - Opções para navegação: Sobre, Desabafo, Doação, Sair.

Estrutura básica:

├── doacao.html

├── script.js
│
└── imgs/
